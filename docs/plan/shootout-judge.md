## Harshest one-line critique per idea

- **F FireSight:** No code at 11:45 and the scope is the widest on this list (3D explode, AR, 12 sources, compliance strip, live MCP); if AR or the pins fail on stage the most memorable beat becomes four grey slabs, and the payer (vendors like First Due) is a guess nobody has confirmed.
- **L2 Cursed Storefronts:** A closed registration is not a failed business (moves, re-registrations, ownership changes all close a record), so "11 businesses died here" is exactly the unverified claim this panel attacks, and the payer is a small tenant who will not pay.
- **R4 RecallChain:** Retailers already get recall feeds from their distributors and GS1-based services, FDA enforcement rows often lack UPCs so most matches land in "possible", and the demo is a CSV table.
- **R2 ParcelScope:** It is FireSight's resolution engine with the specific user removed; "investors, insurers, due diligence" is three buyers, none named, against PropertyShark-style incumbents.
- **L1 Ticket Oracle:** "34% chance" is a base rate dressed as a forecast, the honest user story is "help drivers dodge enforcement" (a responsible-use question a judge will ask), and the citations table is large enough that a count query timed out at 12 s here.
- **L6 1989, Tonight:** The headline "40% not retrofitted" is unverified and the soft-story list FireSight pulled shows tier 2 "Work Complete" rows, so the hero number may be false; insurers already run HAZUS-style scenarios.
- **R1 Recall Radar:** LLM clustering of complaint text is the "everyone has Claude" generic move, NHTSA already links complaints to recalls, and with no exposure denominator a cluster proves nothing.
- **L4 Shazam for Buildings:** Phone GPS and compass error in SF streets will pick the wrong building, there may be no crane within walking distance of the venue, and the buyer list is three guesses.
- **R3 PermitPulse:** Crowded category (permit-lead products already exist) and it turns homeowners' permit records into sales targets, which scores badly on responsible data use.
- **R5 FacilityWatch:** EPA's ECHO site already shows the facility compliance timeline; this is a re-skin with a buyer list.
- **R6 ContractGraph:** GovCon BD tools already sell USAspending graphs; an agency-vendor graph is the "pretty dashboard over public data" the Daylight Principle names as a failure.
- **L5 Call a Building:** A building talking in first person is an AI persona with no buyer; the grounding ("no record") is good but belongs inside a product, and as a layer it costs FireSight an hour for a gimmick.
- **R7 FireFootprint:** Distance to old fire perimeters is a weak risk signal that insurers already buy far better versions of, and using it for underwriting or lending can mislead the decision it claims to inform.
- **L3 Ghost Bus Detector:** A logger started at 11:30 gives about five hours of one weekday, the 511 token is not yet in hand, and Transit-style apps already smooth predictions.
